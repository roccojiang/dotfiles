# Keyboard config files

## [karabiner-ts](karabiner-ts/)

[Karabiner-Elements](https://karabiner-elements.pqrs.org/) configuration, using [karabiner.ts](https://github.com/evan-liu/karabiner.ts).

### Quick start

```sh
npm install       # install dependencies
npm run build     # build & apply to Karabiner profile
```

## [qk75](qk75/)

Laytout exports from [QK Config for Mac](https://www.qwertykeys.com/pages/fw) for the [QK75 Wireless PCB](https://qwertykeys.notion.site/QK75-Wireless-PCB-Guide-bfb296f823c3438fb07e2c2f6adf7e52).
Last updated to [QK75 Mac V1.09](https://www.qwertykeys.com/pages/fw) firmware.

To restore: import [`layout.xml`](qk75/layout.xml) into QK Config and flash to the keyboard.
